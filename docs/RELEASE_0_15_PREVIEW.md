# VIEWS 0.15.0 Preview

Дата выпуска: 12 октября 2026, Ташкент. Новый публичный preview содержит
текущий клиент и отдельный просмотр исходных Canva-макетов всех 140 экранов.
**Это не завершение реализации 84 оставшихся процессов.** Реестр по-прежнему:
56 частично реализованы, 84 pending, полная приёмка всех ID не завершена.

## Состав выпуска

- Кнопка «Canva · 140 экранов» в публичном preview; прямой вход `?design=140`.
- Поиск по ID/названию, роли гостя/CRM/персонала/партнёра/хоста/админа,
  фильтр реального статуса, Light/Dark, ссылки на выбранный экран.
- 280 WebP из предоставленного PDF. Исходный SHA256 проверяется экспортёром;
  manifest содержит страницу, размер и SHA256 каждого изображения.
- Оригинальные макеты русские; оболочка просмотра RU/UZ/EN. Изображения —
  визуальные ссылки, кнопки на них не работают. Это явно написано в интерфейсе.
- Около 8 МБ изображений: веб загружает выбранный макет, APK содержит все.
- Клиент включает локальные блоки уборки, прачечной/претензий, маркета и
  консьержа из коммитов до 5105218. Публичный Core не подключён; сборка APK
  не превращает локальные функции в публичные рабочие сервисы.

## Что ещё не готово

Фото-доказательства и денежные компенсации, техника/трансферы/прокат/экскурсии/
билеты, партнёрский и хостовый сервисные кабинеты, конструктор услуг, расписания,
SLA/эскалации и полная визуальная/функциональная приёмка.
См. [актуальный реестр](design/CANVA_140_DELIVERY.md) и
[остаток блоков](design/CANVA_140_REMAINING_BLOCKS.md).
Публичные email, Core, платежи и реальные партнёры остаются отключены.

## Сборка и проверка

```sh
python3 scripts/export-canva-140.py PATH_TO_OWNER_PDF
npm test
npm run build:review
node scripts/design-review.browser.cjs
npm run build:android
node scripts/design-review.browser.cjs --android
node scripts/android-review-web-proof.cjs
```

Экспорт требует установленного PyMuPDF/Pillow; новые runtime-зависимости не
добавлены. В Git сохранены оптимизированные изображения, поэтому CI не требует PDF.
342 теста в 67 файлах, typecheck и обе сборки прошли. Проверены SHA всех 280
ресурсов, 6 ролей, Light/Dark, три языка, мобильная ширина, фильтры и возврат.
Core в этом изменении не менялся: последние 548 тестов относятся к 5105218.

Android: прежний applicationId `uz.views.preview`, versionCode `1500001`,
Android 8+, прежний preview-сертификат. Подписание выполняется существующим
scripts/sign-android-review.py, ключ не создаётся и не меняется. Установка и
обновление на физическом устройстве не проверены.
