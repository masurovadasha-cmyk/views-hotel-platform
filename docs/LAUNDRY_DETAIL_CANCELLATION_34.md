# Срез34 — отмена прачечной из карточки заказа

Критерии приёмки:
1. Отмена доступна гостю только для requested и действующего заезда; после приёма вещей/выезда остаётся история.
2. Открытие формы и подтверждающий checkbox не отправляют запрос; отправка требует явного согласия.
3. Команда привязана к intakeId/revision; квитанция проверяет тот же ID, cancelled, следующую revision и отсутствие начисленного заказа.
4. Потерянный или неверный ответ сохраняет ключ/тело; offline и переходы не теряют ручной повтор, внешние действия блокируются.
5. Конфликт стадии/revision очищает карточку без автоматической повторной отправки; утрата доступа не раскрывает старые детали.
6. Реальный Core создаёт один audit/outbox отмены, без service_order/начисления; RU/UZ/EN, Light/Dark, mobile проверены в браузере.

Допущения: используем существующий API и миграцию0123; новых таблиц/индексов/сидов/прав не требуется.
Кнопка отменяет заявку до приёма вещей; возвраты обработанных вещей и претензии — отдельные процессы.

Реализация: GuestLaundryCancel показывает review/checkbox; GuestOrderDetail использует прежний hook вне очищаемой карточки.
parseLaundryDetail проверяет revision; guest-laundry-cancel привязывает команду и проверяет квитанцию, INVALID_RESPONSE оставляет ручной retry.
Конфликт очищает snapshot до ручного GET; ключ и тело сохраняются при неизвестном результате, интерфейс счёта не обещает возврат денег.
Новых зависимостей, миграций, прав или изменений действующего направления прачечной нет.
