# Б2 — отдельная гостевая SMS-идентичность

8 октября 2026, Asia/Tashkent. Это программное ядро регистрации/входа, проверенное с **синтетическим адаптером без сети**. Реальная SMS-доставка не подключена.

## API и запуск

`POST /v1/guest-identity/sms` принимает `phone` в E.164 и `locale` ru/uz/en; возвращает только challengeId и сроки. `POST /v1/guest-identity/verify` принимает challengeId/code и возвращает гостевой Bearer token. `GET /v1/guest-identity/session` и `POST /v1/guest-identity/logout` используют `Authorization: Bearer ...`. Ответы no-store. Неизвестные поля тела отклоняются. Сессия не содержит organizationId, membershipId или прав сотрудника.

Пилот требует `NODE_ENV=test`, `VIEWS_LOCAL_REHEARSAL=true`, `VIEWS_GUEST_SMS_PILOT_ENABLED=true`, отдельного `VIEWS_GUEST_SMS_OTP_KEY` из 32 случайных байт в hex и зарегистрированного `GuestSmsDeliveryPort`. **Значение ключа не хранить в Git/чате.** По умолчанию флаг выключен, реестр провайдера пуст. Без адаптера API явно сообщает `GUEST_SMS_NOT_CONNECTED`; имитации успешной отправки нет. Для production локальный пилот не является разрешением активации.

Проверка: из корня `npm run cloud:test:core`; из `apps/api` — `npm run typecheck && npm run build`. Тесты сами создают отдельную PostgreSQL; не использовать постоянную БД для fixtures.

## Хранение и безопасность

Миграция0055: закрытая схема `guest_identity_private`, таблицы sms_challenges/sessions. Runtime не имеет прямого доступа даже на чтение. Узкие SECURITY DEFINER функции с фиксированным search_path выполняют выпуск, отметку доставки, атомарный обмен и отзыв. Общая identity глобальна; организация и её membership не создаются при регистрации гостя. Существующий phone-linked user переиспользуется, права сотрудников через гостевую сессию не раскрываются.

Код — шесть случайных цифр, хранится только HMAC, связанный с challengeId. Срок кода 5 минут, пять попыток; неудачные попытки коммитятся независимо от HTTP-ошибки. Запрос кода: 5/час на телефон, 20/час на сетевой ключ, cooldown 60 секунд под блокировкой телефона. Проверка кода — 60/5 минут на сетевой ключ плюс лимит самого challenge. IP берётся через существующую границу доверенных прокси; телефон в rate-limit key хеширован с секретом.

Новый challenge лишает старый код силы. Обмен одноразовый, параллельные запросы дают одну сессию. Неизвестный результат доставки блокирует обмен; пользователь запрашивает новый код после cooldown. Токен сессии случайный 256-bit, в БД только SHA256; срок 7 дней, logout и неактивный user закрывают доступ. При публикации UI токен должен храниться по правилам платформы: HttpOnly BFF-cookie в вебе, защищённое хранилище мобильного приложения; этот UI ещё не добавлен.

## Подтверждено

Восемь интеграционных тестов под ограниченной ролью: вход/logout, пять неверных попыток, гонка обмена, гонка повторной отправки, uncertain, запрет private-таблиц/отсутствующий адаптер, отключённый synthetic user, default-off/ключ. Дополнительный SQL-тест с откатом проверяет NULL-bypass, истечение кода/сессии, supersession, отсутствие employee membership и переиспользование пользователя. Общий Core383/71 плюс SQL Б1 и SMS; `/tmp/views-b2-sms-verified.log`. Network gate143, Core typecheck/build успешны.

## Открытые условия и ручная приёмка

SMS-оператор/договор/доставка/лимиты/тарифы — **проверить**. Адаптер должен работать через существующую egress-границу, не через прямой fetch. HMAC-ключ, хранение данных по стране, срок хранения challenge/сессий, согласия и защита от SIM-swap требуют приёмки перед публикацией. Очистка истёкших записей и отзыв всех сессий при блокировке/восстановлении аккаунта — Б11; текущая проверка активности запрещает вход, пока user неактивен. SMS не заменяет усиленную авторизацию для финансовых/привилегированных действий.

Гостевая связь с бронированием, публичный checkout, восстановление аккаунта, устройства и экран входа — Б6. Ручная приёмка с настоящим оператором: доставка на тестовые согласованные номера, таймаут/повтор, неверные коды, смена языка, отключение учётной записи, логирование без OTP/токенов/телефона. В этом этапе реальные SMS не отправлялись.
