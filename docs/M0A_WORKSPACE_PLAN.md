# M0a — воспроизводимый workspace: подготовка и разбиение

Исторический preflight; исключение согласовано последующим «следующий шаг».
Итог M0a.1 и команды: M0A_WORKSPACE.md. На момент подготовки:
новый generated pnpm-lock.yaml содержит 5019 строк, прежние два npm-lock —9565.
Ограничение владельца: «Если задача растёт, остановись и предложи разбить».
Нельзя честно представить lockfile такого размера как срез до300 строк.

## Конкретное разбиение
1. M0a.1: импорт существующих lockfiles, workspace manifest, закрепление pnpm,
   добавление Turbo. Ручной diff до300 строк; generated lock отдельным файлом,
   только после согласования исключения. Старые npm-lock остаются до перевода CI.
2. M0a.2: Turbo task graph, typecheck/build/test API и root frontend, CI на frozen
   install; прежние npm scripts продолжают работать. Ручной diff до300 строк.
3. M0a.3: перевод остальных install-путей CI/ops на pnpm, устранение двух
   конкурирующих lock-источников отдельным проверенным срезом. Удаление старых
   lockfiles только после подтверждённой совместимости всех затронутых команд.
