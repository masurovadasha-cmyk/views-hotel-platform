# Canva и код: отдельные реестры приёмки

25 октября родительская дизайн-задача сообщила о доставке 33 редактируемых наборов: 184 уникальных экрана/состояния × 2 темы × RU/UZ/EN = 1104 страницы. Подтверждены 22 сохранения после preview approval; исходные 280 RU-страниц не изменены. Это сведения дизайн-потока, а не результат инженерной проверки каждого макета и не 184 принятых экрана приложения. Pending Canva approval больше не блокирует код.

Номер брони и request key — разные значения. Не показываем синтетические номера как реальные booking IDs. Платёжные токены карт не храним; публичный web/APK не подключает Core, оплату, внешнюю рассылку, доставку или партнёров.

Реестр 140 services ID остаётся в `docs/design/canva-140-delivery.json`; core supplement IDs не прибавляются к его знаменателю. Полная visual/functional acceptance требует отдельного сравнения каждого runtime-состояния. Девять существующих ID изучены в `docs/NINE_SCREEN_VISUAL_AUDIT_20261025.md`; исправления навигации V1 описаны в `docs/V1_ROUTES_QA_20261025.md`.
