# V Market — оставшиеся блоки

Источники: PROGRESS.md, SUPPLY_LOT_IMPLEMENTATION.md и design/CANVA_140_BLOCK_*.md. Не считать весь модуль завершённым по успешным локальным тестам.

| Блок | Статус и приёмка |
|---|---|
| Заказ, согласование замен/количеств, сборка, выдача, гостевой приём, фолио, претензии и бухгалтерская корректировка | Локальные интеграционные и browser proofs существуют; реальные финансовые провайдеры не включены. |
| Происхождение выбранной партии и подтверждённого возврата | L2b–L2e; снимок устаревает после движения, это не живой баланс. |
| Годность записанной партии | L3a: конец календарного дня объекта согласован владельцем; неизвестная дата только вручную. |
| Живые остатки партий | L2f.1 добавил read-only проверочный расчёт (SUPPLY_LOT_PROJECTION_L2F1.md); далее L2f.2: единый ledger всех физических движений, сумма равна SKU, неизвестное происхождение отдельно, backfill только через сверку, конкурентность и rollback. Не включать частично. |
| FEFO / доступность каталога и резерва | После L2f: годные партии, неизвестная годность, дата объекта, перерасчёт доступности без отрицательных резервов, конкурентные брони/выдачи. |
| Фото-подтверждения | Приватное хранилище, загрузка с ограничениями, проверка доступа к заказу, retention и удаление, тесты; не заменять публичными URL. |
| Изменение уже переданного товара | Отдельный сценарий на базе карантина/инспекции и согласия гостя; никаких скрытых возвратов/повторных начислений. |
| Дизайн и выпуск | Полная сверка с Canva, доступность, мобильная приёмка, отдельная авторизация публикации и внешних интеграций. |

До закрытия этих пунктов переход к другому продуктовому направлению как после «полностью готового маркета» недостоверен. Следовать небольшим срезам без повторного согласования обычных изменений.
