Мобильное приложение сейчас Android WebView с общим React-клиентом; Flutter/
React Native и Next.js SEO ещё не реализованы. APK не делает неподключённый
публичный backend доступным. Примерные данные и цены не являются рабочим фондом.

## Что необходимо для реального запуска

Публичный Core с постоянной БД и защищённым хранилищем; рабочие аккаунты и 500
реальных апартаментов; почтовый/SMS-провайдер; юрлицо и договоры платежей,
фискализации и регистрации. Сначала можно завершать внутренние процессы локально.
Реальные внешние операции включаются после технической и юридической приёмки.

Текущий порядок полной реализации: все 140 ID в матрице → внутренние гостевые
услуги → CRM/персонал и SLA → партнёры/хост/конструктор → внешние подключения и
полная приёмка. Исходный объём Б0–Б11 сохраняется в PRODUCT_REQUIREMENTS.md.
