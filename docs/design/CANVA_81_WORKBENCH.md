# Стенд оставшихся81 экранов

Это интерактивная локальная демонстрация, не завершение81 производственного экрана.
Реестр приёмки сохраняет59 partial/81 pending: интерфейсный стенд не заменяет Core, права доступа и полную приёмку PDF.

## Запуск

`npm run build:review`, затем `npm run dev -- --host 127.0.0.1` и открыть
`http://127.0.0.1:5173/?entry=canva-workbench`.
В просмотрщике140 макетов также есть ссылка на стенд.
Роль выбирает демонстрацию, не предоставляет никаких серверных прав.
Все действия в памяти; перезагрузка/смена группы может сбросить данные. Реальные сведения вводить нельзя.

## Проверки и ограничения

`npm test`; `node scripts/canva-workbench.browser.cjs` после сборки.
81 экрана ×2 темы ×2 ширины =324 render/navigation проверки;4 отдельных действия:
переход гостя, обязательный чек-лист, принятие партнёром, обязательные поля конструктора.
Это не проверка всех веток каждого сценария. Выборочные мобильные скриншоты сохранены в /tmp/views-workbench-*.png.
RU интерфейс; UZ/EN ещё не готовы. Карты, реальные документы/фото, цены, выплаты, зарплаты,
API, серверное сохранение, SLA-автоматизация и интеграции не реализованы этим стендом.
Визуальная приёмка81 экранов по PDF не завершена; публичный веб/APK не публиковались.
