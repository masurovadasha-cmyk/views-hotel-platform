# Canva 140: блок 1 — дизайн-система и каталог

Версия: 0.13.0-preview. Базис: b59c009 / 0.12.0-preview.
Источник и полный реестр: CANVA_140_REVIEW.md и CANVA_140_INVENTORY.md.

## Изменения

Общие светлые нейтральные и тёмные графитовые поверхности, золотистая основная
кнопка. Guest/CRM/Core используют общие токены вместо отдельных зелёной/indigo
палитр. Цвет текста акцента отличается от заливки кнопки ради контраста.
Высота многострочного статуса определяется содержимым.

Каталог из восьми направлений: уборка, прачечная, V Market, консьерж, трансфер,
аренда авто, экскурсии, авиа/жд. Ресторан, бар и spa сохранены в дополнительной
группе. Один компонент обслуживает Explore и Services; названия и описания
переведены на RU/UZ/EN. Новые зависимости и внешние запросы не добавлены.

Новые transfer/excursions/tickets имеют null вместо категории отправки: форму
нельзя отправить в legacy API ни через карточку, ни через обработчик submit.
Действующие восемь API-кодов (включая minimart/rent_car) не переименованы.
Смена направления очищает сообщение предыдущего заказа. V Market остаётся
несохранённым списком покупок, а не реальным оформлением розничной продажи.

## Данные, запуск и проверка

Миграции не нужны: это каталог интерфейса, не коммерческий каталог Core.
Цены, сроки, комиссии и названия партнёров из PDF не загружаются как реальные.
Существующие права, схема данных, провайдеры и постоянная БД не меняются.

Использовать существующие зависимости или `npm ci`, затем `npm run build`.
Разработка: `npm run dev`. Открыть гостевой режим → Услуги.

- `npm test`: тесты приложения и полноты динамических переводов каталога.
- `node scripts/service-catalog.browser.cjs`: 54 раскладки, три языка/две темы;
  у новых направлений нет формы и запросов, все восемь старых категорий отправляют
  прежний category/reservationId в тестовый перехватчик. Не реальная отправка.
- `node scripts/canva-design.browser.cjs`: существующие гостевые/CRM/портальные
  сценарии, раскладки и выборочный контраст.
- `node scripts/canva-core-surfaces.browser.cjs`: роли, вход, фолио/склад и поездки
  с новой общей палитрой; HTTP-фикстуры без записей в Core.
- Прежние guest/legacy-staff проверки сохраняют контракт и локализацию.

Результаты рабочего дерева: 311 тестов / 57 файлов; сборка и typecheck;
каталог 54 раскладки; Canva demo 232 раскладки / 126 выборок контраста
(минимум 6,02:1); Core 289 / 2101 (минимум 5,27:1); guest browser,
network primitive gate и 15 mail acceptance проверок. Новые направления
не сделали ни одного запроса. Опубликованный SHA и результаты CI фиксируются
в release notes. Отдельный браузерный тест каталога добавлен в CI.

## Риски и ручная приёмка

Проверить длинные русские/узбекские подписи на телефоне, видимость клавиатурного
фокуса, светлую/тёмную тему в кабинетах и возврат из V Market. Выборочные измерения
не являются полной сертификацией WCAG. APK требует проверки на физическом телефоне.

Не считать этот блок реализацией 140 рабочих экранов: партнёрский портал,
конструктор услуг и сквозное исполнение пока не реализованы этим изменением.
Следующий блок — единый Core-заказ и полный сценарий уборки с заданиями,
инспекцией и начислением, а не восемь отдельных систем заказов.
