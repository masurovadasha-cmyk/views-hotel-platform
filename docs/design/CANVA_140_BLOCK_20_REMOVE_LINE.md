# Canva20 — исключение недоступной позиции до сборки

SG-MK-004/SD-MK-002/SS-MK-001: склад задаёт0 в предложении уменьшения количества. Гость видит только оставшиеся позиции и новую сумму; явное согласие обязательно. Пока согласия нет, исходный состав и резерв сохраняются. Последнюю позицию удалить нельзя: отмена всего заказа остаётся отдельной командой.

Критерии: предложение не меняет резерв; отказ сохраняет исходный заказ; после согласия удалённый товар освобождён полностью; повтор создаёт одного преемника; в фолио начисляется только оставшийся состав; пустая корзина отвергается.

Migration0105 расширяет приватную функцию предложений; quantity0 исключает выбранную строку до расчёта цены. Роли, tenant/ownership, revision, срок предложения, атомарная замена заказа, идемпотентность и audit/outbox остаются прежними. Старые миграции не меняются. Клиентские цена и scope не принимаются.

Форма RU/UZ/EN объясняет0; минимальное значение0 только при нескольких позициях, иначе1. Финальная защита от пустой корзины находится в БД, а не только в интерфейсе. Актуальная цена оставшегося состава требует согласия гостя.

## Запуск
```sh
npm run build
npm --prefix apps/api run typecheck
npm --prefix apps/api run build
npm test
VIEWS_GUEST_EMAIL_HTTP_PROOF=true VIEWS_GUEST_EMAIL_BROWSER_PROOF=true node scripts/cloud-core-tests.cjs src/service-orders/market.input.test.ts src/service-orders/market.integration.test.ts src/service-orders/market-adjustments.integration.test.ts
```
Используется одноразовая PostgreSQL16 с synthetic-данными. Постоянную views_local не сбрасывать.

Ручные проверки: предложить0 в заказе из двух товаров; сверить оставшийся состав/цену у гостя, отказать и проверить резерв; повторить с согласием, провести выдачу и получение, сверить фолио. Проверить последнюю позицию, RU/UZ/EN, Light/Dark и узкий экран.

Ограничения: только до сборки, без автоматической отмены пустой корзины, без компенсаций/провайдерских возвратов. Фото, партии и изменения после сборки остаются открыты. Это расширение частичных экранов, не полная PDF-приёмка; public web/APK этим срезом не публикуются.

Проверено на dirtyc929e0a: Core32, web368, typecheck/build API+web, network187 и mail15 PASS. Connected V Market browser проверяет предложение0, единственную оставшуюся строку у гостя и отказ; принятие/конкурентный повтор/освобождение резерва/фолио проверены PostgreSQL integration test. Новые проверки до изменения падали.
