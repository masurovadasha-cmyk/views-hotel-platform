# SG-GN-004 — Как оплатить?

Источник: сохранённые public/design-140/SG-GN-004-light.webp и dark.webp (PDF страницы4/59). Онлайн-изменения Canva не проверялись.

Схема/миграции не нужны. Полный checkout, eligibility фолио, токен карты и серверная сумма не реализованы.

Проверка: npm run build:review; node scripts/canva-payment-preview.browser.cjs; npm test.

сохранение черновика,0 запросов/ошибок. RU Light/Dark скриншоты просмотрены.
