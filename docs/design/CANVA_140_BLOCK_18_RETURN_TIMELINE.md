# Блок18 — история возврата V Market

Расширение SG-MK-004, SD-MK-002, SS-MK-001: гость и склад видят время фактической приёмки и завершения инспекции рядом со статусом и причиной. Это часть экранов, не полная PDF-приёмка.

Критерии: серверные даты; повтор команды не меняет время; гостевой и складской API возвращают одинаковую историю; старые завершённые возвраты не получают вымышленную дату; RU/UZ/EN; карантин не выглядит завершённой инспекцией.

Миграция0103 добавляет nullable resolved_at и серверный триггер перехода из карантина в restocked/discarded. created_at сохраняется, historical backfill отсутствует. Проверка resolved_at>=created_at. Существующие scope/RLS/permissions и приватный market_receipt сохраняются; персональные данные сотрудника не раскрываются. Новые поля API receivedAt/resolvedAt доступны через существующие списки. Повтор команды возвращает сохранённый receipt. Складские остатки и деньги не меняются этим срезом.

Время явно UTC: API пока не передаёт часовой пояс объекта для возврата. Нельзя выдавать timezone устройства за timezone объекта. Историческая инспекция без даты обозначается «Время не зафиксировано». Новых зависимостей нет.

## Запуск
```sh
npm run build
npm --prefix apps/api run build
VIEWS_GUEST_EMAIL_HTTP_PROOF=true VIEWS_GUEST_EMAIL_BROWSER_PROOF=true node scripts/cloud-core-tests.cjs src/service-orders/market-adjustments.integration.test.ts src/service-orders/market.integration.test.ts
```
Runner применяет миграции в одноразовой PostgreSQL16 с synthetic-данными; persistent views_local не сбрасывать.

## Проверить вручную
- Принять возврат, проверить время приёмки у склада и гостя.
- Выполнить инспекцию/утилизацию, сравнить время в обоих кабинетах после обновления.
- Старые завершённые возвраты: дата инспекции неизвестна, не подставляется время открытия экрана.
- RU/UZ/EN, Light/Dark, узкий экран, чтение подписи UTC.

Риски/остаток: фото, партии, частичная выдача/начисление до получения, provider refund и полная Canva-приёмка не входят. Публичный web/APK не опубликован этим блоком. Следующий срез: частичная выдача с согласованием гостя и точным начислением; разбить отдельно от фото/партий.
