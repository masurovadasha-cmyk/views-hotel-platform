# Блок24 — направления услуг в поездке

SG-GN-006 «Мои заказы», Light6/Dark61: продолжение частичной реализации.
Источник — сохранённый PDF/экспорт; новые изменения онлайн Canva не проверялись.

Критерии приёмки:
1. После открытия поездки показан выбор уборки, прачечной, консьержа и V Market;
   одновременно виден только один рабочий модуль, доступен возврат к выбору.
2. Native-кнопки доступны с клавиатуры, активный выбор обозначен aria-pressed;
   RU/UZ/EN, Light/Dark и ширина390 не вызывают горизонтального переполнения.
3. Посещённые направления сохраняют несохранённые формы только в памяти этой поездки.
4. Неподтверждённая команда блокирует смену направления/возврат; retry сохраняет ключ.
5. После выезда доступны история и существующие разрешённые действия, новые заказы закрыты.
6. При смене поездки или гостевой сессии старые формы и данные уничтожаются.
   Поздний отказ авторизации прежнего запроса не завершает новую сессию.

Схема/API: используются действующие контракты cleaning/laundry/concierge/market;
новые миграции, права и зависимости не нужны. Внешние поставщики не подключаются.
Общий список событий, фильтры по статусам и полная приёмка140 экранов остаются открыты.

Запуск: `npm run dev:local` — существующий disposable Core/PostgreSQL на loopback,
синтетический гость с привязанным проживанием; не использовать реальные документы/платежи.
Проверка: `npm run build`, `npm test`, `npm --prefix apps/api run build`,
`npm --prefix apps/api run typecheck`, `node scripts/core-network-primitive-gate.mjs`,
`node --test scripts/staff-mail.acceptance.cjs`, затем
`VIEWS_GUEST_EMAIL_HTTP_PROOF=true VIEWS_GUEST_EMAIL_BROWSER_PROOF=true node scripts/cloud-core-tests.cjs src/supply src/service-orders src/staff-auth`.

Ручная проверка: клавиатура и читатель экрана; четыре направления и возврат,
смена языка/темы, корзина до отправки, offline и повтор после потери ответа,
новая поездка/выход из аккаунта. Постраничная визуальная приёмка PDF ещё не выполнена.
Публичный веб/APK не меняются этим срезом; подключённые сценарии проверяются локально.
Ограничение: защита неизвестного результата здесь охватывает переходы внутри поездки.
Внешние выход/проверка сессии/привязка новой брони требуют отдельного общего guard.
