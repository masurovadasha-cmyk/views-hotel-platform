# Canva23 — партия и срок годности при приёмке

SD-MK-001: сотрудник склада вводит номер партии и дату годности при частичной или полной приёмке. Журнал движений показывает сохранённые сведения. Старые приёмки явно остаются без сведений о партии.

Критерии приёмки:
- Код1–80 символов и реальная календарная дата0001–9999 передаются вместе либо отсутствуют.
- Одна партия на позицию одной приёмки; несколько партий оформляются отдельными частичными приёмками.
- Повтор команды не дублирует остаток; тот же ключ с другой партией даёт конфликт.
- Данные неизменяемы и доступны только в существующем scope объекта/организации.
- Форма и журнал поддерживают RU/UZ/EN; потеря ответа сохраняет исходные данные и ключ повтора.

Migration0108 добавляет nullable lot_code/expires_on и CHECK к supply_receipt_lines. Старые значения не выдумываются. Используется существующий составной PK при соединении с движениями, дополнительных индексов и зависимостей нет. Манифест дополнен отсутствовавшими0103–0108 без изменения ранее записанных checksum.

Это сведения о поступлении, не остатки по партиям: списание, резерв, возврат и инвентаризация пока работают по SKU. FEFO и блокировка просрочки не подключены; форма сообщает это явно. Прошедшие даты разрешены для достоверной регистрации поступления, а не как разрешение продавать такой товар. Правила допуска продукции — проверить отдельно.
