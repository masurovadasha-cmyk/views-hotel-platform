# VIEWS Master Reference v1.0

Approved 2026-10-04.

## Visual system
Near-black / graphite shell, white and warm ivory surfaces, champagne-gold signal color. Premium hospitality character, mobile-first guest UX, dense professional web CRM.

## Guest
Explore/Search, filters/map, Apartment Details, availability/calendar, booking, guest data, payment-provider handoff, My Bookings, cancellation/refund explanation, Services, Concierge/Messages, Notifications, Favorites/Reviews, Support, Profile.

Guest services: Concierge, Cleaning, Laundry, Mini-market, Restaurant, Bar, Rent Car.

## Staff
Dashboard, Inbox, My Tasks, Service Order Detail, Front Desk, Guest 360, Housekeeping, Maintenance, Messages, Calendar, Shift Handover, Team/Workload, Lost & Found, Damage, Inventory, Finance/Reports, Settings.

Mobile staff: Home | My Tasks | Requests | Chat | More.
Manager: Home | Inbox | Tasks | Team | More.

## Host/Admin
Listings, booking/calendar readiness, integration health, financial read model, moderation, RBAC, audit.

## Truthful data
No fake rates, fees, ratings, financial KPIs, sync states or payment success. Missing data is unavailable/not connected.
